# Słówka

Mini aplikacja webowa do nauki angielskiego słownictwa dla dzieci (ok. 7 lat) przez uzupełnianie brakujących liter.

**Zagraj:** https://damiankisielewski.github.io/slowka/

## Funkcje

- Dwa zadania: uzupełnianie brakujących liter (3 poziomy trudności) albo wpisywanie całego słowa z dużym polskim tłumaczeniem nad okienkami
- 3 próby na słowo, punktacja 3 / 2 / 1, pasek postępu i pozytywne animacje
- Wymowa słów na głos (wbudowany syntezator mowy przeglądarki)
- Zapis postępów w przeglądarce (IndexedDB) i ocena opanowania słów (system pudełek Leitnera)
- Tryb „Powtórka" – częściej słowa, z którymi jest kłopot
- Lista słów: dodawanie, edycja, usuwanie, wyłączanie oraz wklejanie wielu słów naraz
- Eksport i import postępów (plik JSON)

## Uruchomienie

Wszystko jest w jednym pliku `index.html` – bez bibliotek i bez backendu. Wystarczy otworzyć go w przeglądarce albo wejść na stronę powyżej.

Na telefonie: otwórz stronę w Safari / Chrome i dodaj ją do ekranu początkowego – wtedy działa jak aplikacja, a postępy nie są kasowane.

Postępy są zapisane tylko w przeglądarce na danym urządzeniu – do przenoszenia służy eksport / import na ekranie „Moje postępy".
